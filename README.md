# A plugin for taming pets with a unique friendship system

Using this plugin, you have the opportunity to tame pets such as: 

```
> Cat 
> Dog 
> Fox 
> Panda 
> Polar bear 
> Frog 
> Armadillo
```

This plugin also allows you to set a limit on the maximum number of pets, transfer pets to other players, and release pets.

# Attention!!!!

At the moment, the plugin is under active development and does not have many functions! Stay tuned in the "versions" section

# Плагин для приручения питомцев с уникальной системой дружбы

С помощью этого плагина у вас есть возможность приручать таких питомцев, как:

```
> Кошка
> Собака
> Лиса
> Панда
> Белый медведь
> Лягушка
> Броненосец
```

Этот плагин также позволяет вам устанавливать ограничение на максимальное количество питомцев, передавать питомцев другим игрокам и освобождать питомцев на волю.



Внимание!!!!

На данный момент плагин находится в активной разработке и не имеет большинства функций. Следите за обновлениями в разделе «Версии».
